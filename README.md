## Project Description

This project contains my Week 04 JavaScript Fundamentals exercises and mini-projects for the IYF Weekend Academy Season 12.

The project focuses on understanding JavaScript fundamentals and applying them to practical programming exercises, data manipulation, and problem-solving.

## Technologies Used

- HTML5
- JavaScript (ES6+)
- Git
- GitHub

## Features

- **JavaScript Fundamentals:** Variables, data types, operators, conditionals, and functions.
- **Loops and Iteration:** Practice with `for`, `while`, and `for...of` loops.
- **Calculator:** Performs addition, subtraction, multiplication, division, modulus, and exponentiation.
- **Array Manipulation:** Uses `map()`, `filter()`, `find()`, and `reduce()`.
- **Object Manipulation:** Creates, accesses, and modifies JavaScript objects.
- **JSON Operations:** Parses, filters, sorts, and stringifies JSON data.
- **Student Grade Tracker:** Manages student records, calculates averages, assigns letter grades, and generates report cards.
- **Daily Challenges:** Includes FizzBuzz, string reversal, finding the largest number, removing duplicates, and palindrome checking.

   ```bash
   git clone https://github.com/Quantums-meruit/iyf-s12-week-04-Quantums-meruit.git
   ```

   ```bash
   cd iyf-s12-week-04-Quantums-meruit
   ```

3. Open `index.html` in your web browser.

4. Open the browser Developer Tools by pressing `F12`.

## Lessons Learned

This project provides practical experience with:

- Declaring variables using `let` and `const`.
- Working with JavaScript data types and operators.
- Writing reusable functions.
- Using conditional statements and loops.
- Manipulating arrays with built-in array methods.
- Creating and working with objects.
- Handling JSON data using `JSON.parse()` and `JSON.stringify()`.
- Applying JavaScript concepts to solve practical problems.

## Challenges Faced

Some important programming challenges addressed in this project include:

- Handling division by zero in calculator operations.
- Applying the correct array methods to different data problems.
- Accessing and manipulating nested object data.
- Validating student records and grade values.
- Handling JSON parsing safely.
- Combining functions, arrays, objects, and conditionals to build the Student Grade Tracker.
